## Cross-tool handoffs

Read the most recent file in `~/.config/adots/handoffs/` at the start of a session before assuming context is missing. Before ending a session, or when running low on context, write or append today's handoff file there — see `~/.config/adots/handoffs/README.md` for the format. This log is shared with Codex CLI, Gemini CLI, and Antigravity.
